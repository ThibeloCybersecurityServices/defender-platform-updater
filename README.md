# Microsoft Defender Platform Updater

Public binary distribution maintained by Thibelo Cybersecurity Services.

## Latest release

Version 1.6.0

Download: https://github.com/ThibeloCybersecurityServices/defender-platform-updater/releases/tag/v1.6.0

## Installation

Download the MSI matching your Windows architecture (x86, x64 or ARM64).

Verify the installer SHA-256 hash against SHA256SUMS.txt before installation.

## Important information

The MSI packages are unsigned.

Version 1.6.0 passed PowerShell regression, static-analysis, MSI build and
x64 installation lifecycle validation.

Native x86/ARM64 lifecycle testing and Intune field validation remain outstanding.

This repository distributes release binaries, not the development repository.
